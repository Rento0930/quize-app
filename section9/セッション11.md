# セッション11
## データの操作
### 問題となるデータの取得
- 読み込んだjsonからランダムに問題となるデータを1件取得
- 取得したデータの中で、回答になるべきカラムを決定

```
{
  "no": 1,
  "name": "フシギダネ",
  "form": "",
  "isMegaEvolution": false,
  "evolutions": [2],
  "types": ["くさ", "どく"],
  "abilities": ["しんりょく"],
  "hiddenAbilities": ["ようりょくそ"],
  "status": {
    "hp": 45,
    "attack": 49,
    "defence": 49,
    "spAttack": 65,
    "spDefence": 65,
    "speed": 45
  }
}
```

- 仮に`abilities`を正答とする場合、それに合わせたダミーの選択肢を複数取得

### ダミー選択肢の取得
- 読み込んだjsonからランダムにダミーの選択肢を取得
- 正答と被る場合はスキップする対応が必要
- 正答とダミーを合わせて順番をシャッフルし、`answer1~answer4`などの変数に入れておく(選択肢が4個のケース)

### 問題作成

> 取得したデータの中で、回答になるべきカラムを決定

- 上記に合った問題文を生成、もしくは定数として用意したものから選択
- 例として「このポケモンのとくせいは？」を問題文として変数に入れておく
