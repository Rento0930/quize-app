# セッション16
## Firebaseの導入

### 準備
- Firebaseコンソールでプロジェクトを作成し、Authentication機能を有効化
- `@angular/fire` と `firebase` をインストールし、`app.module.ts` で `AngularFireModule` / `AngularFireAuthModule` を初期化
- Firebaseの設定値(APIキーなど)は `environments/environment.ts` に切り出す

### 動作確認の手順
1. Firebaseコンソールの Authentication を開き、ユーザーが登録されていないか確認
2. 登録が無ければ `http://localhost:4200/signup` からサインアップ
   - メールアドレス・パスワードは任意の値でよい
3. 既にFirebase側にユーザー情報が残っている場合は `http://localhost:4200/login` からログイン
4. 同じメールアドレスで再度サインアップしようとすると「既に使用されています」と表示される
   - 同じメールアドレスをもう一度使いたい場合は、Firebaseコンソールのユーザー一覧からそのアカウントを削除すれば再登録できる

## セッションのまとめ
Firebase Authenticationの導入とサインアップ/ログインの基本動作を確認した。次のセッション17でアプリ側の認証機能(ルートガードやログイン状態の管理)を実装していく。

## Tips
- Firebaseコンソールのユーザー削除は、テスト用アカウントの作り直しに使える
- 設定値をコードに直書きせず `environments/` にまとめておくと管理しやすい
